1. Project GoalBuild a clean, useful personal expense tracker that a real person would actually use daily.

Focus on clarity, speed, and reliability over fancy features.Success criteria for MVP:
User can add, view, and delete expenses in under 5 seconds.
Data survives page refresh.
Clear overview of total spending + basic category breakdown.
Looks good on mobile and desktop.
Code is simple enough that a junior can maintain and extend it.


3. MVP Features (Must-have)
Add Expense
Amount (number)
Description (text)
Category (select: Food, Transport, Shopping, Bills, Entertainment, Other)
Date (default = today)

Expense List
Show newest first
Display: amount, description, category, date
Delete button on each item

Summary Dashboard
Total spent (all time or current month)
Simple breakdown by category (total per category)

Persistence
Everything saved automatically to localStorage

Basic UX
Form validation (amount > 0, description required)
Empty state message when no expenses exist
Responsive layout
